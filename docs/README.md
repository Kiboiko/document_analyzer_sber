# Запуск с нуля

Сервис приёма и разбора документов соискателей: соискатель грузит фото
документов, система в фоне распознаёт их моделью и извлекает поля, оператор
проверяет распознанное рядом с оригиналом и правит.

Нужно: Docker Desktop (или Docker Engine + compose v2), свободные порты
`8000`, `8080`, `5432`, ключ ilons для облачной модели.

## 1. Окружение

```bash
cp .env.example .env
```

В `.env.example` по требованию кейса только имена переменных. Для запуска на
своей машине достаточно вписать в `.env` вот эти значения — остальное возьмётся
из умолчаний в `app/config.py` и `docker-compose.yml`:

```dotenv
MODEL_PROVIDER=cloud
ILONS_API_KEY=<ключ ilons — выдают организаторы, в git не класть>

# должен совпадать с секретом клиента docs-app в keycloak/realm-export.json
OIDC_CLIENT_SECRET=dev-only-docs-app-secret
# bootstrap-админ Keycloak (realm master) — через него приложение создаёт операторов
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=admin
# любая длинная случайная строка — подпись cookie сессии
SESSION_SECRET=<случайная строка>
```

Адреса внутри docker-сети (`DATABASE_URL`, `OIDC_ISSUER`, `KEYCLOAK_ADMIN_URL`)
задаёт сам `docker-compose.yml` для `app` и `worker`, в `.env` их писать не
нужно. Значения выше — для локального стенда; на боевом стенде секрет клиента
и пароли меняются в Keycloak и в `.env`.

OCR — HTTP-сервис организаторов, по умолчанию `https://ocr.ilons.ru`
(`OCR_SERVICE_URL`). Проверка доступности: `curl https://ocr.ilons.ru/health`.

## 2. Поднять стенд

```bash
docker compose up -d --build            # postgres, keycloak, app, worker
```

Первый старт Keycloak занимает ~30–60 секунд (импорт realm `docs`).
Локальная модель — отдельно, см. `LOCAL_MODEL.md`.

## 3. Проверить

- `http://localhost:8000/health` → `{"status":"ok", ...}`
- `http://localhost:8000/` — страница соискателя
- `http://localhost:8000/operator` — кабинет оператора (редирект на вход Keycloak)

## 4. Учётные записи

| Кто | Логин / пароль | Где |
|---|---|---|
| Админ кабинета | `admin1` / `admin1` | `http://localhost:8000/admin/operators`. Пароль временный: при первом входе Keycloak попросит задать свой |
| Оператор | создаёт админ на странице «Операторы» | временный пароль показывается один раз, при первом входе меняется |
| Консоль Keycloak | `admin` / `admin` (`KEYCLOAK_ADMIN_*`) | `http://localhost:8080` — нужна только для отладки |

## 5. Что должно получиться

1. **Соискатель** на `/` выбирает гражданство → видит свой набор документов →
   загружает фото (можно несколько файлов на документ). Ответ мгновенный:
   видно, какие файлы приняты, какие отклонены и почему. Статус каждого
   документа меняется сам: «в очереди» → «распознаём…» → «проверен» / «есть
   замечание» / «не распознан» с причиной. Не хватающий документ можно
   дозагрузить в ту же заявку по сохранённой ссылке.
2. **Воркер** в фоне берёт задачи из очереди (до 4 одновременно), распознаёт
   файлы (OCR → LLM), проверяет поля по правилам, сверяет ФИО и даты между
   документами. Документ обычно готов за 20–40 секунд.
3. **Оператор** входит через Keycloak, видит список заявок с фильтрами
   (гражданство, статус документов, ФИО), открывает карточку: фото слева,
   распознанные поля справа, замечания подсвечены. Правит поле (отмечается
   как правка оператора) или запускает повторный разбор. Раздел «Очередь» —
   какие документы ждут и разбираются прямо сейчас, плюс цифры.
4. **Админ** создаёт операторов на странице «Операторы».

Перезапуск (`docker compose restart`) ничего не теряет: заявки, файлы и
очередь — в Postgres и томе; незаконченные задачи воркер подхватит сам.

## Проверка API из Windows PowerShell

Сервер отдаёт JSON в UTF-8 с `Content-Type: application/json; charset=utf-8`,
поэтому `Invoke-RestMethod` читает кириллицу верно. Если кириллица всё же
превращается в `Р˜Р’Р...`, дело в чтении файла, а не в сервере:

- `curl.exe -o ответ.json ...` сохраняет байты как есть (в UTF-8, без BOM).
  `Get-Content` в Windows PowerShell 5.1 без параметра читает файл в кодировке
  ANSI (windows-1251). Читайте так: `Get-Content ответ.json -Encoding UTF8`.
- Не передавайте результат через `Out-File`/`>` в 5.1 без `-Encoding utf8`:
  по умолчанию это UTF-16 с BOM.
- В PowerShell 7 кодировка по умолчанию уже UTF-8, и этих оговорок нет.
