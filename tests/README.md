# Проверки

Сценарные проверки своей части (Степан: модельный слой, приём, страница
соискателя, сопоставление). Это обычные скрипты, а не pytest: зависимостей
не добавляют, запускаются по одному и печатают, что именно проверено.

## Что чем проверяется

| Файл | Нужна БД | Что проверяет |
|---|---|---|
| `test_validate.py` | нет | правила раздела 3 ТЗ на всех 8 типах: формат серии/номера, даты в будущем, просрочка -> `flagged`, нехватка минимума -> `error` |
| `test_model.py` | нет | модельный слой против подставных olmOCR и LLM: форма запросов, нормализация, грязный ответ модели, ошибки провайдеров, переключение `cloud`/`local` |
| `test_intake_e2e.py` | да | приём: токен, дедуп по sha256, отказы по типу и размеру, одна задача на документ, события, статусы для поллинга, страницы соискателя |
| `test_crosscheck.py` | да | сопоставление ФИО и дат: транслит, порог, повторный прогон без дублей, снятие расхождения после правки оператором |

`test_model.py` не ходит в сеть: `httpx.AsyncClient` подменяется на
`MockTransport`, поэтому проверяется настоящий код запросов, а не заглушка
вокруг него.

## Запуск

Тестам, которым нужна БД, достаточно любого пустого Postgres: **схема
пересоздаётся с нуля**, поэтому боевую базу подставлять нельзя.

```bash
docker run -d --name pg_test \
  -e POSTGRES_USER=app -e POSTGRES_PASSWORD=app -e POSTGRES_DB=app \
  -p 55432:5432 postgres:16-alpine

export PYTHONPATH=.
export DATABASE_URL=postgresql+asyncpg://app:app@127.0.0.1:55432/app
export STORAGE_DIR=/tmp/da_test_files

python tests/test_validate.py
python tests/test_model.py
python tests/test_intake_e2e.py
python tests/test_crosscheck.py

docker rm -f pg_test
```

Код возврата: `0` — всё прошло, `1` — есть провалы (в конце печатается список).

## simulate_worker.py

Не тест, а заглушка воркера: записывает в документ поля так, как это сделает
`worker.process_job`, и выставляет статус по `validate_document`. Нужна, чтобы
показать страницу соискателя с разобранным документом, пока воркер ещё не
готов. После появления настоящего воркера — удалить.

```bash
python tests/simulate_worker.py <applicant_token>
```
